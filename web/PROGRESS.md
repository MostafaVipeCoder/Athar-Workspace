## Deviations from 06 (and why)

1. No `data/*.hooks.js` split: hooks sit next to functions in `programs.js`/`canvas.js`/`staff.js` (fewer files at this size). Consequence for tests: pages are tested with full module mocks that re-implement the hooks.
2. `.env.development` (committed) not used: the root `.gitignore` ignores `.env.*`, so `dev:local` runs mode `development` and reads the git-ignored `.env.local`. `dev:live` not created (needs the owner's go-ahead).
3. Roles come from `user_roles` directly: the migrated DB has no `get_user_roles` RPC.
4. `/profile` lives inside PublicShell (any signed-in user), not a staff shell.
5. Node `ports` shape follows the DB (`families[]`, `kind`, `cardinality`, `required`) instead of 06's single `type` string.
6. Note node has no `node_types` row, so it is demonstrated only with the in-memory adapter.

8. Missing translations of the skip link and the English "planned for" text on placeholders (placeholders are temporary).
9. Vite chunking: react/router and supabase-js are the heavy vendor chunks; they load on every page.
